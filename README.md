# SmartCode AI Studio

AI-powered code review and bug detection system.

## Features
- AI Code Analysis
- Bug Detection
- Complexity Analysis
- Security Suggestions
- Optimized Code Suggestions

## Installation

```bash
npm install
```

## Run Project

```bash
node server.js
```

Open:
http://localhost:3000

## Environment Variables

Create .env file:

```env
GROQ_API_KEY=your_key_here
```
